Фото для телефона

Фото для компьютера

Заменит img/Image_1_desktop.jpg. Лучше горизонтальное, например 2560×1440.

Старый файл перезаписывается новым с тем же именем, любой формат конвертируется в JPEG. После замены сайт обновится через 1–2 минуты, а браузер может ещё некоторое время показывать старое фото из кэша (обнови страницу сайта с Ctrl+F5).
